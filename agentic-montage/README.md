# Agentic Montage

A real-time simulation of the agent-based media-montage system: the agent reads
a corpus of declassified documents and speaks about what it sees, in subtitles,
over a montage that keeps moving.

Live at `/sites/agentic-montage/`.

## The corpus

Pages from the USA Government UAP release, chosen across handwritten reports,
teletype memoranda, a newspaper clipping, a photostat checklist and an Air Force
intelligence requirement, so the montage keeps changing texture.

- `corpus.js` is the manifest — the only file you edit to change the piece.
- `media/01.jpg` … are the pages.
- Each entry keeps `ref`, the archival reference for the page, and `summary`,
  the pipeline's summary of it, verbatim.

Every subtitle in `lines` is an excerpt cut verbatim out of that page's summary,
so the agent only ever speaks its own description of what is on screen. The
manifest is generated by locating each excerpt in a normalised copy of the
summary and slicing it out of the original, which means an excerpt that is not
really in the summary is reported rather than silently written.

The page loops through the entries in order, forever. The size of the corpus is
never shown on screen, so entries can be added or removed without the page
announcing how much there is.

## Preparing images

From the release scans:

1. Greyscale.
2. Invert if the mean is below 100 — photostats are white type on black, and
   inverting puts every page at the same density behind the subtitles.
3. Trim the scanner surround: threshold at the 5th–90th percentile midpoint,
   keep rows and columns where more than 15% of pixels are above it.
4. Autocontrast, cutoff 0.5.
5. Fit inside 1250 × 1500 and save as progressive JPEG, quality 82.

Ten pages come to about 2.8 MB. On a landscape screen the plate is opened out
past the frame (`inset: -26%`) so a portrait page fills the width instead of
letterboxing to half of it, and the drift crops it; portrait screens show the
page whole.

## Changing the corpus

1. Put the pages in `media/`.
2. Point `src` at them in `corpus.js`.
3. Write `lines` — these are the subtitles, and their combined length decides how
   long each page stays on screen. Three lines is roughly twenty seconds.
4. Optionally add `audio: "media/01.mp3"` for a voice-over. If any entry has
   audio the page opens with a click-to-begin gate, because browsers block
   autoplay. Subtitle timing stays driven by `lines`, not by the audio file.

An entry with `src: null` falls back to a procedurally generated scan, seeded by
its slot in the list, so the loop is identical on every run. A `src` that 404s
falls back the same way rather than showing a blank frame.

## Controls

- `space` pause / resume — everything runs off one clock, so it stops exactly
- `c` hide the chrome (columns, timecodes, footer), leaving montage and subtitle
- `f` fullscreen
- on touch, tap anywhere to pause

The cursor hides after three seconds. For a conference: load the page, `f`, then
`c` if you want the bare projection. The montage pauses by itself when the
window is hidden and resumes without jumping, so a machine left on the page
overnight will not have drifted.
